# 2Screen Repo

APT repository for **2Screen** (`com.mia.2screen`) — a CarPlay two-screen tweak for VinFast VF3.

Add to Sileo (once):

```
https://henrysido.github.io/2screen-repo/
```

Then refresh sources and install / upgrade **2Screen** from Sileo. No manual `.deb` download needed.

## Layout (flat APT repo)

- `Release` — repo description
- `Packages`, `Packages.bz2`, `Packages.gz` — package index (generated by `dpkg-scanpackages`)
- `debs/` — the `.deb` files (old versions kept so Sileo can downgrade)

## Release process

Run `./update-repo.sh <path-to-new.deb>` on the VM after a verified build, then push the text files; upload the `.deb` itself via the GitHub web UI (binary files cannot go through the Muse GitHub connector).
